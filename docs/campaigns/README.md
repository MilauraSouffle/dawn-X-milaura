# Registre des sélections saisonnières MilAura

Date de création : 2026-09-23

Ce dossier conserve le manifeste technique de chaque campagne récurrente. Le site public utilise le hub `/pages/selections-saisonnieres`; il ne présente jamais ces pages comme des archives périmées.

## Règle de classement

Chaque occasion maintenue possède un dossier stable :

- `automne/`
- `noel/`
- `saint-valentin/`
- `fete-des-meres/`
- tout autre temps fort validé par Patrice

Chaque dossier contient au minimum un `manifest.md` avec l URL publique, le cycle de vie, les produits, les médias, le copywriting validé, les destinations externes et les preuves de release.

## Cycle de vie

- `DRAFT` : thème privé ou collection non publiée.
- `ACTIVE` : campagne mise en avant sur la Home Occasion.
- `OFF_SEASON` : URL conservée, contenu périmé retiré, page toujours utile depuis le hub.
- `RETIRED` : cas exceptionnel après audit SEO, Analytics, backlinks et liens internes.

Les pages consacrées à une pierre ne sont pas rangées ici comme des campagnes saisonnières. Elles restent des destinations permanentes sous `/collections/par-pierre-...` et sont reliées depuis les guides du site.
