## Décision créative

- Chloé porte réellement les bijoux. Elle n'est pas un élément décoratif.
- La boucle, le collier, la bague et le bracelet forment une seule lecture visuelle, de l'oreille vers la main.
- Les bijoux restent à leur échelle anatomique réelle. Le bracelet de 6 mm est seulement un peu plus large que le collier de 4 mm.
- Le visage est recadré pour empêcher le regard de devenir le premier point d'attention.
- Le décor est aigue-marine profond, avec une ombre améthyste et une chemise ivoire. Aucun fond beige dominant.
- Le texte reste du HTML dans le thème. Aucun texte n'est intégré à la photographie.
